# Linux Security Labs

Laboratórios práticos de Linux voltados para Segurança da Informação.

## Objetivo

Este repositório documenta minha evolução prática em Linux, administração de sistemas e fundamentos de Segurança da Informação.

## Laboratórios

| Nº | Tema | Status |
|---|---|---|
| 01 | Fundamentos Linux | Base contruída |
| 02 | Usuários e Privilégios | Concluído |
| 03 | Permissões e Controle de Acesso | Próximo |

## Tecnologias utilizadas

- Ubuntu Linux
- Terminal Linux
- Git/GitHub
- Conceitos de Segurança da Informação

- ## Principais conhecimentos desenvolvidos

- Administração básica de usuários Linux;
- Gerenciamento de grupos;
- Controle de privilégios com sudo;
- Princípio do menor privilégio;
- Conceitos de autenticação e autorização;
- Organização de documentação técnica.

- ## Próximos laboratórios

- Permissões de arquivos (chmod, chown e chgrp);
- Processos Linux;
- Gerenciamento de serviços;
- Logs e auditoria;
- Hardening Linux;
- Redes Linux.
