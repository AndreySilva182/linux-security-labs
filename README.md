# Linux Security Labs 🐧🔐

Repositório criado para documentar minha evolução prática em Linux, Redes e Segurança da Informação através de laboratórios realizados em ambiente virtual.

O objetivo é desenvolver uma base sólida em administração Linux, controle de acesso, processos, serviços, auditoria e fundamentos utilizados em ambientes corporativos de Segurança da Informação.

---

# Sobre o Projeto

Este repositório reúne laboratórios práticos desenvolvidos em ambiente Linux, documentando:

- comandos utilizados;
- conceitos aplicados;
- análises realizadas;
- evidências práticas;
- aprendizados obtidos.

A abordagem utilizada é baseada em resolução de problemas e investigação, simulando situações encontradas em ambientes reais.

# Laboratórios

## 🐧 Lab 01 — Fundamentos Linux

### Objetivo

Compreender os principais conceitos do sistema operacional Linux, sua estrutura de arquivos e comandos básicos.

### Conceitos praticados:

- navegação no terminal;
- estrutura de diretórios;
- gerenciamento de arquivos;
- comandos básicos Linux;
- utilização do shell.

📁 Pasta:

```text
01-fundamentos-linux
```

---

# 👥 Lab 02 — Usuários e Privilégios Linux

### Objetivo

Compreender o gerenciamento de usuários, grupos e permissões administrativas.

### Conceitos praticados:

- criação de usuários;
- gerenciamento de grupos;
- UID e GID;
- privilégios administrativos;
- utilização do sudo;
- separação de privilégios.

📁 Pasta:

```text
02-usuarios-e-privilegios
```

---

# 🔐 Lab 03 — Permissões e Controle de Acesso

### Objetivo

Aplicar controle de acesso utilizando permissões Linux e o princípio do menor privilégio.

### Conceitos praticados:

- leitura, escrita e execução;
- proprietário e grupo;
- chmod;
- chown;
- controle de acesso baseado em usuários.

### Conceito de segurança aplicado:

> Usuários devem possuir somente as permissões necessárias para executar suas funções.

📁 Pasta:

```text
03-permissoes-controle-acesso
```

---

# ⚙️ Lab 04 — Processos e Serviços Linux

### Objetivo

Entender como processos e serviços funcionam dentro do Linux.

### Conceitos praticados:

- identificação de processos;
- PID;
- monitoramento de recursos;
- encerramento de processos;
- gerenciamento com systemctl;
- análise de serviços ativos;
- interpretação de logs de serviços.

Ferramentas utilizadas:

```bash
ps
top
systemctl
journalctl
kill
```

📁 Pasta:

```text
04-processos-servicos-linux
```

# 📋 Lab 05 — Logs Linux e Auditoria de Eventos

### Objetivo

```bash
journalctl
loginctl
```

📁 Pasta:

```text
05-logs-e-auditoria-linux
```
